# Dataset

All data in this project is **synthetic** and intended exclusively for learning and portfolio use.

## Files

- `raw/sales_performance_cameroon.xlsx` — source workbook containing the sales data, dictionary and KPI guide.
- `database/sales_performance_cameroon.db` — SQLite database used by the SQL and Python analysis.

## Scope

- 5,000 sales transactions.
- Cities: Douala, Yaoundé, Bafoussam, Dschang and Bamenda.
- Customer segments: Particulier, PME and Revendeur.
- Payment methods: MTN MoMo, Orange Money, Espèces, Carte bancaire and Virement.

The Excel sales table, SQLite fact table and Power BI semantic model have been synchronized to the same 5,000 transactions.

No real company, customer or employee data is used.
